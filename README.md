# GitHub Training Project - Leon Template

## وصف المشروع
مشروع ويب تعليمي يهدف لتطبيق مهارات التعامل مع Git و GitHub. القالب عبارة عن صفحة هبوط (Landing Page) احترافية لوكالة إبداعية، وتتميز بتصميم عصري ومتجاوب.

## التقنيات المستخدمة
* **HTML5**: لهيكلة محتوى الموقع.
* **CSS3**: للتنسيق واستخدام نظام (Grid) والمتغيرات (Custom Properties).
* **Google Fonts**: خط (Work Sans).
* **Font Awesome**: للأيقونات التوضيحية.

## مميزات المشروع (Bonus)
* **Responsive Design**: الموقع متوافق مع كافة أحجام الشاشات (Mobile, Tablet, Desktop).
* **GitHub Pages**: المشروع منشور ويعمل أونلاين.

## خطوات التشغيل
1. قم بتحميل المشروع أو عمل `git clone`.
2. افتح ملف `index.html` باستخدام أي متصفح ويب.
